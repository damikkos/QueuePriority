# QueuePriority - админский приоритет

QueuePriority добавляет админский приоритет и резервные слоты на сервер DayZ 1.29. Админский приоритет получают игроки, чьи SteamID указаны в `QueuePriority.ini`.

Для работы нужен [KR_GRAFTED v0.2.0](https://github.com/KRdayzmodding/KR_GRAFTED).

## Админский приоритет и очередь

- **Обычная очередь.** Игрок ждёт своей очереди на свободное место.
- **Стандартный приоритет в очереди.** Игрок из `priority.txt` получает преимущество в очереди, но не доступ к резервным слотам.
- **Админский приоритет.** Игрок из `QueuePriority.ini` становится первым, в том числе перед игроками из `priority.txt`, и может занять свободный резервный слот.

Резерв входит в общий лимит `maxPlayers`. Если в настройках сервера указаны 40 мест и 5 мест админского резерва, Steam и лаунчер показывают игрокам сервер на 35 слотов. Резервные места в этот публичный лимит не входят. Игроки с админским приоритетом сначала занимают резерв, а после его заполнения используют обычные места.

Даже когда все видимые игрокам слоты заняты, игрок с админским приоритетом может войти через свободное место в резерве. Он становится первым в очереди, а остальные сдвигаются назад, сохраняя порядок. Ждать ему придётся, только если на сервере совсем не осталось свободных мест.

Обычная очередь и стандартный приоритет через `priority.txt` продолжают работать.

Движок обновляет отображаемый лимит примерно раз в минуту. Число подключённых игроков при этом остаётся фактическим.

## Установка

1. Установите KR_GRAFTED на сервер.
2. Поместите `QueuePriority.grafted.dll` в папку `DayZServer/grafted/`.
3. Запустите сервер. Если `QueuePriority.ini` отсутствует, плагин создаст его рядом с DLL.
4. Укажите в нём число резервных слотов и SteamID игроков с админским приоритетом.

После замены DLL перезапустите сервер.

## Настройка

Новый `grafted/QueuePriority.ini` содержит две строки:

```ini
ReservedSlots=0
SteamID=
```

В `ReservedSlots` задайте число резервных мест; `0` отключает резерв. В `SteamID` укажите Steam64 ID из 17 цифр для игроков с админским приоритетом. Разделяйте ID пробелами, запятыми или точками с запятой либо добавляйте отдельные строки `SteamID`.

Настройки применяются при следующем добавлении игрока в очередь, без перезапуска сервера. Существующий файл плагин не перезаписывает.

## Сборка

Для сборки нужны Windows x64, Visual Studio 2022 с C++ Clang tools, CMake версии 3.30 или новее и Ninja. Положите исходники KR_GRAFTED v0.2.0 рядом с папкой QueuePriority:

```text
mods/
  KR_GRAFTED/
  QueuePriority/
```

Запустите в папке QueuePriority:

```bat
build.cmd
build\rules_test.exe
```

Готовая DLL появится в `build/QueuePriority.grafted.dll`. Путь к KR_GRAFTED можно изменить параметром CMake `QUEUE_PRIORITY_GRAFT_DIR`.

## Совместимость и журнал

Плагин проверен на DayZ Server 1.29.163709. Если он не распознаёт версию движка, то не меняет работу сервера и записывает причину в журнал.

Ищите сообщения с `[QueuePriority]` в файлах `graft_*.log` в папке профиля сервера.
